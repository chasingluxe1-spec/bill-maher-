# Thumbnail Prompt Template (gpt-image-2, 3 variants)

Base skeleton (fill [BRACKETS] per video):
```
A YouTube thumbnail, 1280x720: a real editorial-style documentary still — [SUBJECT: the victim
or the case's key place/object] in a serious, respectful composition, muted cinematic color
grade, subtle vignette. At most a short factual hook in clean bold sans-serif (upper or lower
third): "[SHORT VERIFIED HOOK]". Restrained true-crime / long-form-journalism aesthetic
(Frontline / The Atlantic), NOT a red-and-yellow reaction-channel look. High contrast, legible
at small size.
```

Vary the 3 variants by:
1. **Subject** — victim portrait vs the key evidence/object vs the location.
2. **Crop/composition** — close portrait vs wider scene.
3. **Text** — one variant with the hook, one minimal, one text-free.

Hard rules (see rule 05):
- **Never** fabricate a photorealistic face standing in for the real victim/suspect — prefer an
  authentic sourced still composited with generated background/text.
- **No** fake quotes, fake confessions, fabricated arrest scenes, gore, or misleading imagery.
- The hook must be a **verified fact** the video fulfills; no "new evidence" claims when none
  exists, no "BREAKING" on an old case.
